# README 界面截图

根目录 [README.md](../../README.md) 的「界面预览」章节按**固定文件名**引用本目录图片。
更新或替换截图时，只要保持文件名不变即可，**无需改动 README**。

## 文件清单

| 文件名 | 对应页面 | 画面内容 |
|---|---|---|
| `login.png` | 登录页 `/login` | 左右分栏：左侧品牌与能力介绍（AI 徽标、能力卡片、六阶段流程），右侧登录表单（用户名 / 密码 / 图形验证码） |
| `dashboard.png` | 首页（AI 工作台）`/` | 欢迎横幅与快捷入口、四个 KPI 磁贴、项目全流程导航卡片、团队工时可视化 |
| `project-overview.png` | 项目概览 `/overview` | 项目全流程地图（需求 → 计划 → 架构 → 开发 → 交付 → 运营）+ 当前环节工作台 |

## 截图建议

- **格式与尺寸**：PNG；宽度 1280～1600 px（Retina 屏可 2x 截图后缩放）；单张尽量 ≤ 500 KB。
- **窗口**：浏览器窗口约 1600×1000，隐藏书签栏与扩展图标，截取视口即可（三张保持同一宽度观感更整齐）。
- **账号与数据**：截图会进入公开仓库，请使用 `python manage.py seed_demo` 生成的**合成演示数据**
  （演示账号如 `demo_manager` / `demo12345`，项目「演示项目 · 客户工单管理系统」），
  **不要使用真实客户或项目数据**。
- **一致性**：首页与项目概览建议登录同一个演示账号、选中同一个演示项目后再截，保证三张图数据自洽。
